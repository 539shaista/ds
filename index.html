Mathematical Reference & Prediction Methodology

Normal Prediction (Continuous) Fitted using sample mean \(\hat{\mu} = \bar{X}\) and standard deviation \(\hat{\sigma} = s\). Predicts continuous probabilities via the Gaussian PDF and error function \(\text{erf}\).
Binomial Prediction (Discrete Trials) Fitted by estimating the success rate \(\hat{p} = \bar{X} / n\) given trials \(n\). Predicts exact outcome probabilities \(P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}\).
Poisson Prediction (Count Rate) Fitted by estimating rate \(\hat{\lambda} = \bar{X}\). Ideal when variance is close to the mean (\(s^2 \approx \bar{X}\)). Predicts event frequency \(P(X = k) = \frac{\lambda^k e^{-\lambda}}{k!}\).
